# 네이버 쇼핑몰 광고 효율 분석 & 최적화 대시보드 (`naver-ad-optimizer`)

네이버 검색광고·쇼핑검색광고 API 실시간 연동 및 엑셀/CSV 다차원 보고서 자동 분석을 통해 **ROAS 개선, 광고비 누수 키워드 차단, 목표 마진율 기반 적정 입찰가(CPC) 산출**을 지원하는 반응형 웹 애플리케이션(PWA)입니다.

## 주요 기능
1. **네이버 검색광고 API 실시간 연동 & 보고서 1초 업로드 분석**
   - `CUSTOMER_ID`, `Access License`, `Secret Key`를 통한 실시간 캠페인·소재·키워드 조회
   - 네이버 광고 보고서(`.csv`, `.tsv`, `.txt`) 드래그 앤 드롭 즉시 파싱
2. **AI 4대 광고 효율 최적화 추천 엔진**
   - 🚨 **광고비 누수 차단**: 지출 대비 전환 0건 또는 손익분기 미달 키워드/상품 자동 추출 및 원클릭 제외 키워드 복사
   - 🚀 **고효율 스케일업**: 목표 ROAS 달성 중이나 노출순위가 낮은 효자 상품 입찰가 상향 추천
   - 🎨 **CTR(클릭률) 개선 진단**: 노출 대비 클릭률이 저조한 상품 썸네일·상품명 개선 대상 추출
   - ⚖️ **과열 입찰가 인하**: 전환은 발생하나 CPC 과열로 적자인 항목의 적정 입찰가 인하 폭 제시
3. **24시간 무료 클라우드 동기화 (GitHub `db-store` & Google Drive)**
   - 아이폰(iOS), 아이패드(iPadOS), PC 브라우저 간 24시간 실시간 동기화 및 홈 화면 앱 설치(PWA) 지원
